# Firebase phone OTP API

## Prerequisites

Set `FIREBASE_WEB_API_KEY` in `.env`, enable the Firebase Authentication Phone provider, authorize `malisetu.com`, allow India in the SMS region policy, and clear Laravel's configuration cache.

`recaptcha_token` must be a fresh Firebase `RecaptchaVerifier` result generated by the client application. The literal text `FIREBASE_RECAPTCHA_TOKEN` is only a placeholder and will not work. Generate a new token for send and resend because Firebase reCAPTCHA proofs expire quickly and cannot be reused.

## Variables

```bash
BASE_URL="https://malisetu.com"
PHONE_NUMBER="+919876543210"
RECAPTCHA_TOKEN="PASTE_FRESH_FIREBASE_RECAPTCHA_TOKEN"
```

## 1. Send OTP

```bash
curl --location --request POST "$BASE_URL/api/auth/phone/send-otp" \
  --header "Accept: application/json" \
  --header "Content-Type: application/json" \
  --data-raw "{\"phone_number\":\"$PHONE_NUMBER\",\"recaptcha_token\":\"$RECAPTCHA_TOKEN\"}"
```

Successful response:

```json
{
  "success": true,
  "message": "OTP sent successfully.",
  "data": {
    "phone_number": "+919876543210",
    "session_info": "FIREBASE_SESSION_INFO"
  }
}
```

Save `data.session_info`; it is required to verify the SMS code.

## 2. Verify OTP

```bash
SESSION_INFO="PASTE_SESSION_INFO_FROM_SEND_RESPONSE"
OTP="123456"

curl --location --request POST "$BASE_URL/api/auth/phone/verify-otp" \
  --header "Accept: application/json" \
  --header "Content-Type: application/json" \
  --data-raw "{\"session_info\":\"$SESSION_INFO\",\"otp\":\"$OTP\"}"
```

Successful response includes `data.verified: true`, the verified `phone_number`, Firebase UID, Firebase ID token, token lifetime, and whether Firebase created a new user.

## 3. Resend OTP

Generate another reCAPTCHA token first. Do not reuse the send token.

```bash
NEW_RECAPTCHA_TOKEN="PASTE_NEW_FIREBASE_RECAPTCHA_TOKEN"

curl --location --request POST "$BASE_URL/api/auth/phone/resend-otp" \
  --header "Accept: application/json" \
  --header "Content-Type: application/json" \
  --data-raw "{\"phone_number\":\"$PHONE_NUMBER\",\"recaptcha_token\":\"$NEW_RECAPTCHA_TOKEN\"}"
```

Use the new `data.session_info` returned by resend when calling the verify endpoint.

## Generate the web reCAPTCHA token

```javascript
import { initializeApp } from 'firebase/app';
import { getAuth, RecaptchaVerifier } from 'firebase/auth';

const app = initializeApp({
  apiKey: 'YOUR_FIREBASE_WEB_API_KEY',
  authDomain: 'YOUR_PROJECT.firebaseapp.com',
  projectId: 'YOUR_PROJECT_ID'
});

const auth = getAuth(app);
const verifier = new RecaptchaVerifier(auth, 'recaptcha-container', { size: 'normal' });
const recaptchaToken = await verifier.verify();
```

Postman cannot generate this proof itself. Copy it from an authorized browser client and use it immediately.
